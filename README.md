## Review basis

Prepared October 22, 2026 against SnapPDF 0.2.1+8005, package com.techtyphoon.snappdf. Reviewed Flutter dependencies and lockfile, Android dependencies, main and merged release manifests, backup rules, native file sharing/import/export/print/scanning, ML Kit integration, encrypted signature storage, local settings, library index and trash/cache cleanup. This is a source/configuration review, not a runtime network-traffic certification. The policy distinguishes local document processing from the separate Google Play services process and does not claim Google diagnostics are disabled.
